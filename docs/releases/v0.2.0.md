# AnimeLab v0.2.0

## Changes

- Added in-app release download, SHA-256 verification, and platform installation (`POST /api/app/updates/install`, `GET /api/app/updates/install`, `POST /api/app/updates/apply`) across Android (`PackageInstaller` self-update with certificate verification) and desktop archives (`.zip`, `.tar.gz`), with live progress tracking in the startup update view and Settings.
- Replaced the `"Continuer la configuration"` button label with `"Continuer"` on the new release presentation screen.
- Fixed the anime detail hero card and cover backdrop in both Dark and Light themes across all palettes (`AnimeDetailView.vue`, `themes.css`, `style.css`), replacing the unblurred duplicate cover background and hardcoded white text with a blurred ambient backdrop and high-contrast theme tokens.
- Definitively fixed the `"La source n’a renvoyé aucun épisode pour cette série."` bug across Aniyomi sources: added full support for Anime-Sama's new inline `lien:<id>` / `epsJeton` / `epsMeta` episode database format and `/api/lien.php` resolver (prioritizing live mirrors and refreshing expired tokens), `.oe-panneau` season/film cards, root catalogue fallback, Wiflix `onclick` player links, Madara AJAX chapter lists, and single-episode film fallbacks on Vostfree and DooPlay.
- Fixed Aniyomi and Seanime repository imports failing with `HTTP 403` on Bot-Guard protected hosts such as Codeberg (`codeberg.org`) by syncing the default Chrome TLS User-Agent with `curl_cffi` (`Chrome/150.0.0.0`) and adding an automatic `AnimeLab/0.2.0` fallback retry.
