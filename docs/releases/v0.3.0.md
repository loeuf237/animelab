# AnimeLab v0.3.0

## Changes

- **Native French-Stream source (`fstream.net` → `fs016.lol`)**: Integrated French-Stream alongside VoirAnime, AnimePahe, and French-Manga with automatic mirror discovery from `fstream.net`, series and film scraping, hoster resolution, per-source settings, catalogue browsing, search, and UI integration (`1c8d27f`).
- **External media player support on Desktop & Android (`#49`)**: Play local or streamed episodes in `mpv`, `VLC`, custom player executables, or the default system player on Linux/Windows/macOS (auto-detected even when preset is `none`) and via Android `FileProvider` / `NativeUiBridge` intents, including watch-progress confirmation prompts (`337c6f4`, `1c8d27f`).
- **Offline library anime details & local episode management**:
  - Mihon-style SQLite persistence for library anime detail pages with offline cover caching, background updates when online, and manual refresh (`1c8d27f`).
  - Fixed downloaded episodes re-streaming instead of playing locally on Desktop disk and Android SAF/MediaStore (`content://` range streaming), hid subtitle selection and re-download options on already-downloaded episodes, and added direct episode deletion from anime detail views while preserving watch progress (`1c8d27f`).
- **Built-in video player & Android playback fixes**: Restored next/previous episode navigation across streaming and local playlists (preserving language scope) and resolved Android embedded video player playback, fullscreen, and orientation bugs (`bcb2db0`).
- **Community Telegram onboarding & Settings About (`#71`)**: Added an invitation to join the Telegram support/updates group (`https://t.me/AnimeLabGroup`) during first-run onboarding and displayed the link in Settings → About (`7d0c05f`).
- **Seanime extension runtime on Android**: Fixed `SeanimeJsBridge` Kotlin/Chaquopy JVM interoperability (`@JvmStatic` exports), eliminated blank-page `CountDownLatch` load races, fixed WebView lifecycle (`onResume`/`resumeTimers`/`WebChromeClient`), isolated sequential `evaluateJavascript` shim initialization, added call-scoped `fetch()` cancellation and Cloudflare verification propagation parity (`VerificationRequired` URL forwarding and shared `_BaseSeanimeRuntime` store/TTL caching) (`6b2cc7a`).
- **Aniyomi / Anikku engine improvements (Android + PC)**:
  - Enabled `OkHttpClient.networkInterceptors` cleanly inside `GatewayInterceptor` / `RealInterceptorChain` without sockets, added `explicitNulls = false` and shared `app.cash.quickjs.` / `org.jsoup.` / `mihon.core.` / `tachiyomi.core.` packages in `ExtensionRuntimeService`, handled `FetchType.Seasons` multi-season episode expansion, added v16 `getHosterList` to `getVideoList` fallbacks, deduplicated stale APK `cf_clearance` cookies in `extension_http()`, and wired isolated `clear_cookies` across verification completion (`6b2cc7a`).
  - Audited 15 random SFW extensions from the Yuzono repository and shipped generic parser & container fixes: request/search path reconstruction (bare `&`, trailing `=`, `/search/title/{query}`, `/page/1` 404 fallback), base URL path preservation (`/v1`), Jsoup `:contains` / `:containsOwn` selector translation, pagination selector exclusion, `*FromElement` title extraction, hub/ad link filtering, Bootstrap `data-content` popover episode expansion, and clean `APIOnlyExtensionError` (`unsupported/api_only_apk`) classification for JSON/GraphQL APKs on desktop (`6b2cc7a`).
- **Mihon-style isolated WebView verification (Android & Desktop)**:
  - Android `VerificationActivity`: Chrome Mobile User-Agent normalization, in-app navigation toolbar (`✕`, `←`, `→`, `↻`, progress bar, `Terminer`), multi-URL `CookieManager` capture/flushing, in-WebView popup routing, and automatic closure after clearance verification (`6b2cc7a`).
  - Desktop PC: Dedicated ephemeral GTK3 + WebKit2GTK WebView window on Linux (`linux_verification_webview.py` with `HttpOnly` cookie IPC), pywebview support on Windows (`WebView2`) / macOS (`WKWebView`), and compact `--app` Chromium window fallback with target reuse (`Page.navigate`), single-click primary `"Vérifier dans la WebView"` prompt UX, `"Ouvrir en WebView"` actions on sources and anime pages, and `POST /api/network/webview/open` (`6b2cc7a`).
- **Documentation & Showcase refresh**: Refreshed French & English READMEs, showcase demo video/GIFs/screenshots, and post-v0.2.0 roadmap/contribution priorities (`7554229`, `406b004`).
