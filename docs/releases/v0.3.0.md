# AnimeLab v0.3.0

## Changes

- **Seanime extension runtime on Android**: Fixed `SeanimeJsBridge` Kotlin/Chaquopy JVM interoperability (`@JvmStatic` exports), eliminated blank-page `CountDownLatch` load races, fixed WebView lifecycle (`onResume`/`resumeTimers`/`WebChromeClient`), isolated sequential `evaluateJavascript` shim initialization, added call-scoped `fetch()` cancellation and Cloudflare verification propagation parity (`VerificationRequired` URL forwarding and shared `_BaseSeanimeRuntime` store/TTL caching).
- **Aniyomi / Anikku engine improvements (Android + PC)**:
  - Enabled `OkHttpClient.networkInterceptors` cleanly inside `GatewayInterceptor` / `RealInterceptorChain` without sockets, added `explicitNulls = false` and shared `app.cash.quickjs.` / `org.jsoup.` / `mihon.core.` / `tachiyomi.core.` packages in `ExtensionRuntimeService`, handled `FetchType.Seasons` multi-season episode expansion, added v16 `getHosterList` to `getVideoList` fallbacks, deduplicated stale APK `cf_clearance` cookies in `extension_http()`, and wired isolated `clear_cookies` across verification completion.
  - Audited 15 random SFW extensions from the Yuzono repository and shipped generic parser & container fixes: request/search path reconstruction (bare `&`, trailing `=`, `/search/title/{query}`, `/page/1` 404 fallback), base URL path preservation (`/v1`), Jsoup `:contains` / `:containsOwn` selector translation, pagination selector exclusion, `*FromElement` title extraction, hub/ad link filtering, Bootstrap `data-content` popover episode expansion, and clean `APIOnlyExtensionError` (`unsupported/api_only_apk`) classification for JSON/GraphQL APKs on desktop.
- **Mihon-style isolated WebView verification (Android & Desktop)**:
  - Android `VerificationActivity`: Chrome Mobile User-Agent normalization, in-app navigation toolbar (`✕`, `←`, `→`, `↻`, progress bar, `Terminer`), multi-URL `CookieManager` capture/flushing, in-WebView popup routing, and automatic closure after clearance verification.
  - Desktop PC: Dedicated ephemeral GTK3 + WebKit2GTK WebView window on Linux (`linux_verification_webview.py` with `HttpOnly` cookie IPC), pywebview support on Windows (`WebView2`) / macOS (`WKWebView`), and compact `--app` Chromium window fallback with target reuse (`Page.navigate`), single-click primary `"Vérifier dans la WebView"` prompt UX, `"Ouvrir en WebView"` actions on sources and anime pages, and `POST /api/network/webview/open`.
