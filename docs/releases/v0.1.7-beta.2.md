# AnimeLab v0.1.7-beta.2

## Changes

- Native cross-platform UI redesign: edge-to-edge Android system bars and haptics, five-tab mobile bottom navigation, `More` hub, desktop theme sync and in-app confirmation dialogs.
- Progressive anime catalogue streaming over NDJSON with shimmer loading placeholders and smoother route transitions.
- Fixed the endless Android screen-flicker loop during extension APK updates and upgraded Aniyomi APK install/update UX (inline progress, confirmation reopen, permission prompts and signature-conflict recovery with explicit `versionCode` + SHA-256 trust).
- Fixed Android private App Data bloat: private staging copies now clean up automatically after verified export, on download removal, history clearing and startup, plus a one-tap `Free private storage` action and full four-permission display in Settings.
- Hardened Android update detection (`v*` and `android-v*`), external APK download links, crash/error diagnostics export, first-run onboarding completion and VoirAnime migration to `voiranime.cx` (plus reusable APK compatibility report from PR [#44](https://github.com/loeuf237/animelab/pull/44) by [Mr-Neutr0n](https://github.com/Mr-Neutr0n)).
