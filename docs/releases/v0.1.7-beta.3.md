# AnimeLab v0.1.7-beta.3

## Changes

- Integrated Seanime marketplace and onlinestream extensions alongside Aniyomi across desktop (`mini-racer`) and Android (`SeanimeJsBridge`), including repository catalog management, stabilized JS runtime shim, diagnostics, HTTP 502 error mapping and per-episode `VF`/`VOSTFR` version detection.
- Desktop native window improvements: bundled `pywebview` (`6.2.1`), added a self-contained Linux GTK3/WebKit2GTK subprocess window host (`linux_gtk_window.py`), and surfaced clearer fallback errors in `NativeLauncher`.
- True AMOLED pitch-black theme (`#000000` surfaces and Android system bars with contrast scrim disabled on API 29+) plus authentic Mihon Classic Blue (`Classique`) dark and light Material 3 palettes.
- Multi-season and download reliability fixes: deduplicated JetAnime DooPlay episode lists while excluding sidebar links and preserving season metadata (`S01E01`), assigned unique episode row keys and season-aware sorting/filenames in the detail view, fixed filename collisions for versions/titles containing `/` (`VOSTFR / VF`, `Fate/stay night`), ensured unique save paths across seasons (including Plex layout), and auto-cancelled legacy conflicted paused tasks on relaunch.
- Media & SPA hardening: proxied hotlink-protected VoirAnime/AnimePahe posters with high-resolution `srcset` preference and prevented stale Service Worker / HTML caching across upgrades.
