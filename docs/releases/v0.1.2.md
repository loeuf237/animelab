# AnimeLab 0.1.2 — source recipes and HTTP host protection

This release includes the Python engine, the compiled Vue interface and media tools. Python and Node.js do not need to be installed separately.

## Changes since 0.1.1

- Imported source updates use atomic replacement and version-specific APK caches, while preserving configured source domains.
- Source catalogue filters, ordering and pagination have been corrected. Supported imported sources run through the shared declarative recipe interpreter; redundant per-source runtime adapters have been removed.
- French Anime no longer receives the similarly named Hanime recipe. Contaminated saved recipes are repaired, restoring the source's intended catalogue and filters.
- Incoming HTTP hosts are validated before routing, CORS and CSRF checks. `localhost` and `127.0.0.1` are accepted by default; LAN and reverse-proxy deployments must configure `ANIMAN_ALLOWED_HOSTS` with the addresses or domains used to reach the application. `ANIMAN_RELOAD` behavior is unchanged.
- Development dependencies are locked, CI enforces linting and typing checks, and tests share offline DNS with isolated caches. Direct backend-only pytest runs skip the SPA serving test without a frontend build; CI still requires the build.
- The project is licensed under **GPL-3.0-only**. Existing mobile layout, playback, download resume and storage/export improvements remain included.

## Desktop packages

| Platform | Archive | Validation |
| --- | --- | --- |
| Windows x64 | `AnimeLab-v0.1.2-Windows-x64.zip` | Automated packaged backend, interface and media checks |
| Linux x64 | `AnimeLab-v0.1.2-Linux-x64.tar.gz` | Automated package checks; Ubuntu 22.04 / glibc 2.35 baseline |
| macOS Apple Silicon | `AnimeLab-v0.1.2-macOS-arm64-UNTESTED.zip` | **UNTESTED on real Mac hardware**; automated package checks only |
| macOS Intel | `AnimeLab-v0.1.2-macOS-x64-UNTESTED.zip` | **UNTESTED on real Mac hardware**; automated package checks only |

Extract the complete archive and launch `AnimeLab.exe`, `./AnimeLab` or `AnimeLab.app`. Existing libraries and settings remain in the user's data directory, outside the archive. FFmpeg and ffprobe are bundled; the native window uses the system WebView with an installed-browser fallback.

macOS packages are **not Developer-ID signed or notarized**. Linux packages require compatible system libraries and are not universal AppImages. Automated checks do not validate every desktop environment or guarantee access to external sources. Each platform includes build provenance; `SHA256SUMS.txt` covers the release assets.

The matching Android build is published separately as **0.1.2 beta 1**. Source code for this desktop release is available from the `v0.1.2` tag in this repository.
