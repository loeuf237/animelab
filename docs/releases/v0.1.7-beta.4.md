# AnimeLab v0.1.7-beta.4

## Changes

- Synchronized `DEFAULT_USER_AGENT` with `curl_cffi`'s active `DEFAULT_CHROME` profile instead of a hardcoded `Chrome/125` string, fixing `HTTP 403` (`Access denied, old Chrome version.`) errors when importing Aniyomi repositories hosted on Codeberg (such as `aniyomi-extensions-fr`).
- Added automatic `User-Agent: AnimeLab/0.1.7` fallback retry on `HTTP 403` for Aniyomi catalog/APK downloads (`extension_service.py`) and Seanime repository/manifest fetches (`seanime_service.py`), protecting desktop, server, and older Android 10 WebView devices alike.
