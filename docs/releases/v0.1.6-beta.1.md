# AnimeLab v0.1.6-beta.1 — Beta: APK extensions and WebView session recovery

## Major Changes

This is a **beta/pre-release on every platform**. All earlier GitHub releases
are now classified as pre-releases too; their original tags and downloads remain
available. This version includes the current extension-management and WebView
work, rather than rebuilding the older main branch.

The Android beta explicitly enables the **experimental Aniyomi/Anikku APK
runtime**. It executes original installed extension APKs through the native host,
with per-version/signer trust and the Android package installer. Extensions
already installed as shared Android packages can be discovered without rewriting
their APKs. This is not a claim that every extension or site works.

**Known session limitation:** the worker's complete cookie store still needs to
be unified with the main WebView store. A blocked site can remain blocked after
a WebView visit. The full community catalogue → episodes → video path and the
new WebView behavior still need physical-device acceptance. The beta is not
approved for production use by the APK01–APK14 criteria.

## Added

- **Android extensions:** explicit trust/revocation, real PackageInstaller
  operations and cancellation, source preferences, recursive native filters,
  source identities and aliases. These native APK features remain Android-only.
- **Persistence:** private original anime/episode references and callback memos
  survive engine restart and external APK uninstall/reinstall. Quota failures
  roll back a batch without silently evicting library references.
- **Media:** native hosters/videos and resolution callbacks, private temporary
  capabilities for supported video, HLS and subtitle resources.
- **Validation:** controlled original-APK fixtures on Android API 29/30/35,
  optimized ARM64 builds and a guarded physical-device test driver.
- **Documentation:** detailed Aniyomi/Anikku extension and WebView/session studies.

## Changed

- **WebView:** SourceHTTP waits for active handles to finish, then suspends new
  requests to the verification domain while the WebView owns that session.
  No emulated HTTP probe is sent during that window, including challenge-check
  requests. Automatic proxy rotation for the domain is suspended too.
- **Return to the app:** capture the browser cookies, stop the WebView, then
  resume waiting source operations. Session import is reported separately from
  successful site access.
- **Release channel:** all newly published artifacts use an explicit beta tag;
  the publisher marks them as pre-releases and does not advertise them as stable.
- **Android:** version 0.1.6, version code **219**, package `com.animan.app` and
  existing production signing certificate preserved. The experimental runtime
  is enabled for this beta; ordinary stable release builds keep it disabled.

## Fixed

- The verification watcher no longer launches an extra GET while the WebView
  is open or closes it prematurely when a cookie changes.
- Failed or partial native window shutdown retains session ownership until
  cleanup succeeds; cancelled startup cannot later claim an orphaned session.
- Derived source clients retain their application interceptors, redirect
  policies and bounded read timeouts through the Android broker.
- Legacy detail parsers may omit uninitialized URL/title fields; their original
  identity is retained. Nullable fields and absent video headers stay distinct.
- Opaque native memos remain private rather than being exposed in anime/episode
  responses. Runtime errors retain typed codes instead of appearing as an empty
  video list; a working hoster can still succeed when another fails.
- Explicitly disabled extensions stay disabled after reinstalling their APK.

## WebUI

The compiled Vue interface is bundled in every package. The native extension
panel includes inspection, approval, operation states, cancellation and source
configuration. Returning from verification says that a session was recovered;
the actual source operation determines whether access succeeds.

macOS packages are unsigned and not notarized. Stop the old desktop server
before replacing its application files, preserving your existing user data.
Android keeps its signing identity; do not uninstall an existing compatible
installation just to update.

Publication requires all five platform packages, same-commit build manifests,
the expected Android certificate, emulator gates and
[SHA-256 checksums](https://github.com/loeuf237/animelab/releases/download/v0.1.6-beta.1/SHA256SUMS.txt).
No validation/test APK, signing key or experimental N_m3u8DL-RE binary is a
public release asset. DASH with extension headers, separate audio, styled ASS,
player command arguments and full private extension-state backup remain
incomplete. The worker shares the app UID and is not a sandbox for hostile APKs.
