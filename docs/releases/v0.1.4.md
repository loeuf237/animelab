# AnimeLab v0.1.4 — Accounts, native authentication and unified downloads

## Major Changes

### Android and desktop in one release

The signed Android APK now appears alongside Windows, Linux and macOS downloads. Publication requires all four desktop packages and the Android emulator checks to succeed. Every package comes from the same tagged source revision, with build provenance and SHA-256 checksums.

### Optional accounts and private workspaces

Enable authentication in the desktop launcher's new Authentication tab or deploy the shared server behind HTTPS. Administrators manage accounts, permissions, invitations and recovery codes. Each account has its own library, downloads, settings, cookies and engine process. Personal mode remains the default, and existing personal data is not moved automatically.

## Added

- **(Accounts)** Administrator-managed users, expiring sessions, password changes, single-use invitation/recovery codes and per-account download/extension permissions.
- **(Isolation)** Private account workspaces, bounded engine processes and authenticated media/API access.
- **(Launcher)** An eleventh Authentication tab, first-administrator setup, session policy and account-management access.
- **(Release)** Production-signed ARM64 Android APK, emulator validation on Android API 29, 30 and 35, and one publication gate for all platforms.
- **(Validation)** Packaged authentication and account-engine startup checks in addition to desktop launcher and native-window checks.

## Changed

- **(WebUI)** Vue is the sole web frontend. Old page bookmarks redirect to their corresponding Vue screens while preserving search parameters.
- **(Launcher)** Darker native text, readable French/English labels and balanced tab rows.
- **(Dependencies)** Removed the unused Jinja2 frontend and its direct template dependencies. The Python package is now named `animelab`; compatibility-sensitive application identifiers and existing user directories are preserved.
- **(Android)** Version name 0.1.4 and version code 217 retain the existing package ID and production signing certificate for updates.

## Fixed

- **(Authentication)** Account switching clears browser state; disabled accounts, expired sessions and revoked access cannot continue using another account's resources.
- **(Desktop)** Frozen executables can launch private account engines, including Windows builds without a console.
- **(Navigation)** Legacy anime, downloads, search and settings links resolve to the current interface.
- **(Offline)** Service-worker updates discard obsolete page caches and exclude authenticated account/API/media responses from offline caching.

## WebUI

The compiled Vue application is included in both Android and desktop packages. Authenticated installations offer account controls and administrator tools. The former Jinja pages are no longer distributed.

For desktop, extract the **entire archive** and open the launcher. Python, Node.js, FFmpeg and ffprobe are bundled. For Android, install the signed APK on a compatible ARM64 device running Android 10 or later.

**macOS packages are unsigned and not notarized.** Linux native WebViews require compatible GTK/WebKit libraries; browser mode is available. The Android release has not been tested on every physical device, and the complete ARM64 media pipeline is not certified by the emulator checks. Source availability depends on third-party sites.

**Updating:** stop the previous desktop server before extracting the new archive into a separate directory. Preserve your user data. Android updates require the same package and signing identity; no uninstall is needed for a compatible previous production-signed APK.

Account workspaces are separate from the existing personal library. A public shared server requires HTTPS and a dedicated origin. Per-account disk quotas and cross-account file deduplication are not implemented.

[SHA-256 checksums](https://github.com/loeuf237/animelab/releases/download/v0.1.4/SHA256SUMS.txt) cover all five packages and their provenance manifests. Download links and build information are also listed under **Assets** below.
