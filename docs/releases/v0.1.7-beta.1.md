# AnimeLab v0.1.7-beta.1 — Native cross-platform UI redesign, progressive catalogue streaming and Android diagnostics

## Major Changes

### Native cross-platform UI redesign

AnimeLab now adapts its chrome, spacing, navigation and dialogs to the host platform across Android, desktop and browser environments. On Android, `MainActivity` enables edge-to-edge rendering while `NativeUiBridge` synchronizes status and navigation bar colors, icon contrast and tactile haptic feedback with the active palette, paired with a five-tab bottom navigation bar and a dedicated `More` hub. On Windows, Linux and macOS, the PyWebView host and Qt launcher synchronize light/dark appearance and expose native window/directory actions cleanly. Destructive confirmation prompts across History, Downloads and Extensions now use accessible in-app dialogs rather than blocking `window.confirm()` popups.

### Progressive anime catalogue streaming

Large source listings now stream incrementally over NDJSON via `/api/sources/{source_id}/catalogue/stream` (`RecipeRuntime.expand_listing_stream` and `source_catalogue`). Instead of waiting for an entire multi-page or detail-enriched scrape to finish on slower connections, cards appear progressively with an animated shimmer skeleton grid and subtle poster fade-in transitions as images load.

### Android update detection, crash reporting and diagnostics

Android update checks, external release download links and failure reporting are substantially hardened. Release feeds parse both desktop (`v*`) and Android (`android-v*`) beta/stable tags reliably, `MainActivity.onCreateWindow` handles `WebViewTransport` popups cleanly so release APK downloads open in the external browser, and native uncaught exceptions as well as WebView crashes are recorded by `CrashReporter` and surfaced through `GET /api/diagnostics/export` alongside global Vue/window error telemetry (`POST /api/diagnostics/report`). Users on Android can now export sanitized diagnostics directly into `Downloads/AnimeLab` via `MediaStore`, copy a structured bug summary, or open a prefilled GitHub issue.

### Experimental Android APK runtime (Beta)

This beta keeps the **experimental Aniyomi/Anikku APK extension runtime** enabled (`version 0.1.7`, version code **223**, package `com.animan.app` and existing production signing certificate preserved).

## Added

- **(UI)** Platform-aware design tokens, native OS styling sheets, bottom-sheet modal styles, `PosterCard`, responsive `SkeletonGrid`, five-tab `AppBottomNav` and the `MoreView` hub across Android, desktop and web.
- **(Streaming)** Incremental NDJSON catalogue stream endpoint (`/api/sources/{source_id}/catalogue/stream`) with live client consumption and shimmer loading placeholders.
- **(Android)** `NativeUiBridge` (system bar synchronization, haptic feedback, `MediaStore` diagnostics export) and `CrashReporter` (uncaught thread exceptions and WebView/engine startup failures persisted in private storage).
- **(Diagnostics)** `POST /api/diagnostics/report` client error ingestion, `recentErrorCount` and `lastCrash` fields in `GET /api/diagnostics/export`, global Vue/browser error listeners in `frontend/src/main.ts`, plus one-click summary copy and GitHub issue links in `DiagnosticsExport`.
- **(Docs)** Reusable Aniyomi/Anikku APK compatibility report added from PR [#44](https://github.com/loeuf237/animelab/pull/44) alongside refreshed showcase and contributor documentation.

## Changed

- **(VoirAnime)** Migrated the default VoirAnime base URL from `voir-anime.to` to `https://voiranime.cx` across source services, extractors and regression tests.
- **(Settings)** Fixed horizontal alignment and card padding in `AppUpdateSettings` so the application-and-updates panel lines up evenly with surrounding General settings cards.
- **(Desktop)** Updated `DesktopBridge`, Qt launcher widgets and panel styling so native desktop controls follow the selected theme and palette.
- **(CI)** Increased CI frontend and Python job timeout budgets from 15/20 minutes to 30 minutes to prevent runner cancellations.
- **(Android)** Bumped `versionName` to `0.1.7` (`versionCode` **223**) and default runtime `User-Agent` to `AnimeLab/0.1.7`.

## Fixed

- **(Updates)** Fixed Android update detection across `android-v` and `v` tags (`per_page=10`, bounded request timeouts) and fixed `target="_blank"` release download links getting dropped by Android `System WebView` (`WebViewTransport`).
- **(Diagnostics)** Preserved `NativeUiBridge`, `CrashReporter` and `@JavascriptInterface` entry points under R8 minification in `proguard-rules.pro`, resolved `ANIMAN_DATA_DIR` fallback on Android when reading `last_crash.json`, and prevented stale `diagnostics` errors during crash inspection.
- **(Android Tests)** Updated `EmbeddedEngineTest` to recognize `.home-top-header` in the redesigned home view and to assert live `/api/diagnostics/report` and `/api/diagnostics/export` round-trips on physical ARM64 hardware.

## WebUI

The compiled Vue interface is bundled inside every Android and desktop release archive from the exact same tagged source. Platform navigation, progressive catalogue loading, theme palettes and diagnostics export share unified API contracts across all targets.
